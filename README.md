# Studies Preparation

Interactive GitHub Pages site for tracking fully funded master's scholarships, application portals, prerequisites, documents, deadlines, and fit.

Live site after GitHub Pages deployment:

`https://rweg.github.io/studies-preparation/`

## What This Includes

- Scholarship cards with official application links
- Collapsible prerequisites per scholarship
- Funding coverage and document requirements
- Search and filters by status and fit
- Private preparation checklist stored in browser local storage
- Official source links and verification notes
- Coverage gap records for research-master funding, course-level DAAD calls, admission-linked fellowships, Mastercard partner calls, and source-conflict/stale pages

## Research Boundary

The dataset focuses on major fully funded international master's scholarships relevant to a Rwandan/African applicant profile, plus broader university and research-degree routes found during the 17 August 2026 audit. Scholarship status changes quickly. Always verify the official page before submitting.

## Update Data

Edit:

`data/scholarships.json`

Then commit and push to update the website.
